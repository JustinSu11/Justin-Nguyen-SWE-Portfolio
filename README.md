# Justin Nguyen - Portfolio (v2.0)

Single-page static site. No build step, no dependencies.

## Structure

    index.html          markup
    css/styles.css      all styles
    js/main.js          orb, scroll snapping, hands animation, accents
    assets/images/      painting and hands artwork

## Run locally

    npx serve .

(or open index.html in a browser)

## Deploy

Vercel: framework preset "Other", no build command, output directory ".".

## Versions

- v1.0: Next.js portfolio (git tag `v1.0`)
- v2.0: this site (git tag `v2.0`, branch `v2`)
